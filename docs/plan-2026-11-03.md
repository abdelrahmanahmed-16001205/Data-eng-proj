## 5. Animation spec

Source: `animate`, `find-animation-opportunities`, `review-animations` (Emil Kowalski's rules).
Gate applied — four of seven candidates survive; the rest are rejected below.

### Tokens to add to `:root`

```css
--ease-out: cubic-bezier(.23, 1, .32, 1);
--ease-in-out: cubic-bezier(.77, 0, .175, 1);
--dur-fast: 120ms;
--dur-base: 200ms;
```

Extend the existing token layer; do not fork a second one.

### Build

| # | Location | Today | Purpose | Frequency | Motion |
|---|---|---|---|---|---|
| 1 | `app-final.js:51` `render()` | Twelve charts teleport | Preventing a jarring change | Occasional | Fade `.charts-grid` `opacity: .55 → 1`, 140ms `--ease-out`. Not `0 → 1` |
| 2 | `styles.css:215` | Colour change only on press | Feedback | Tens/day | `:active { transform: scale(.98) }`, `transform 120ms --ease-out`, `background-color 120ms ease` |
| 3 | `app-final.js:52` first load | Charts pop in after "Data ready" | Preventing a jarring change | Once per visit | Same fade, 200ms, opacity only |
| 4 | Theme toggle (after dark mode) | Instant full-page flip | Preventing a jarring change | Rare | `document.startViewTransition` circular reveal, 400ms; instant fallback |

### Rejected

- **Animated bar growth / line draw-in.** Functional data being read; 2,540-node SVGs; re-runs on
  every Generate.
- **Hover lift on chart cards.** Decoration on data reading.
- **Scroll reveal on sections.** ~4,000px of prose.
- **Map dot fade-in.** 5,100 nodes.
- **Skeleton shimmer.** A looping animation for a once-per-visit wait.
- **Sliding Q-tab indicator.** Keyboard-driven, frequent — near-imperceptible or nothing.

### Two corrections to the current code

- `styles.css:473` sets `transition: none !important; animation: none !important`. The rule is
  *gentler, not zero*: keep opacity and colour, drop transform.
- **Do not put `transform` on the twelve panels.** 13,312 DOM nodes, 5,100 in the map: twelve
  composited layers of heavy SVG trades a flash for scroll jank. Animate the wrapper's opacity.

## 6. Dark mode

Prerequisite: the token layer conflates text colour and surface colour. `--ink` is both body text and
the fill of `.section-bar`, `.impact-block`, `.chart-panel`'s top rule and the focus ring. Split it
into `--ink` (text), `--bar` (dark surface) and `--rule` (strong line) before adding a dark palette.

Measured candidates for the dark set (contrast, WCAG AA = 4.5 text / 3.0 UI):

| Pair | Ratio |
|---|---|
| body `#c9d4d1` on ground `#0f1416` | 12.21 |
| ink `#eef3f1` on paper `#171e21` | 15.05 |
| note `#93a3a0` on chart ground `#131a1c` | 6.70 |
| green text `#4ec98b` on ground | 8.88 |
| ink `#0b1310` on sign green `#34b57a` | 7.21 |
| white on sign green `#34b57a` | 2.61 — fails, so the sign inverts to dark-on-green |
| red `#ff7a6b` on chart ground | 6.92 |
| input border `#64777b` on paper | 3.59 |

Also required: `color-scheme: dark` on the root (otherwise native selects and scrollbars stay light),
`<meta name="theme-color">` per scheme, an inline pre-paint script reading `localStorage` to avoid a
flash, and a print stylesheet that forces light.
